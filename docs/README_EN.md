# 📚 Windows Disk Cleanup Automation Builder - Documentation (English)

Welcome to the official English documentation for **Windows Disk Cleanup Automation Builder (`v1.5.0`)**, a high-performance utility designed to generate optimized disk cleanup automation scripts (`.bat` / PowerShell) and standalone portable executables (`.exe`) via `cleanmgr.exe` and Windows Registry modifications.

---

## 🌐 Multilingual & Localization Support (v1.5.0)

Starting with **v1.5.0**, Disk Cleanup Automation Builder features **automatic system locale detection** (supporting Korean `ko`, English `en`, and Japanese `ja`), automatically adapting:
- **Graphical User Interface (GUI) & Web Preview**: Localized buttons, tooltips, log messages, and status messages.
- **Generated Script Comments**: Comments inside generated batch scripts and PowerShell automation scripts are automatically formatted in the user's detected language.
- **Corporate Affiliation & Credits**: Displays corporate affiliation `(주)청운정보시스템` (`cisnet.co.kr`) and author credits (`AhBiYout`).
